# Security Policy

## Supported Versions

For security and stability reasons, only the latest version of the Bot is officially supported.

Older versions may continue to function but:

- Do not receive security updates
- May contain unresolved vulnerabilities
- May lack important bug fixes and new features

Potential security issues may exist in versions prior to `v2.3.1`, especially versions using older Firebase implementations.

| Version | Supported |
| ------- | --------- |
| 2.3.1   | ✅ Yes    |
| < 2.3.1 | ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability or potential exploit, please report it as soon as possible.

Reports can be submitted through:

- Discord Server: https://discord.gg/cgdssWTqAT
- Email: [Philippesmeets@icloud.com](mailto:Philippesmeets@icloud.com)
- Discord: `philippesmeets`

When a report is received:

1. The issue will be reviewed and validated
2. The severity and impact will be evaluated
3. Security-related issues will be prioritized for resolution

Please do not publicly disclose vulnerabilities until the issue has been resolved.

## Security Updates

Security updates, patches, and important fixes are only guaranteed for the latest supported version.

Users are strongly encouraged to keep their installations updated to reduce security risks.
