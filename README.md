Apex Legends Bot is your ultimate companion for everything related to _Apex Legends_.  
Get live player stats, map rotations, server status, rank information, and more.

Start by typing `/` in Discord to view all available commands.

## Features

### 🎮 Live Player Stats

- View real-time stats for players across Steam, EA, PlayStation, and Xbox
- See equipped legend, trackers, account level, Battle Pass progress, and ranked stats

### 🌐 Apex Legends Server Status

- Check real-time server status to ensure optimal gameplay

### 🗺️ Map Information

- View current Battle Royale and Mixtape maps
- See full map rotation schedules for active events

### 🎲 Random Legend Selector

- Instantly select a random legend when you can’t decide who to play

### 🏆 Apex Predator Threshold

- View current Apex Predator RP thresholds across all platforms

### Much much more!

- 15+ slashcommands
